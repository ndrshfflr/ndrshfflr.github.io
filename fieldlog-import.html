Clean your eBird file

Merlin Bird ID saves your birds in eBird. eBird's “Download my data” file holds the exact coordinates of every sighting, and the files on this website are public. This page keeps only what the field log needs and drops the rest.

  1. On ebird.org → My eBird → Download my data, request your data. It arrives by email as a .zip — unzip it.
  2. Choose the MyEBirdData.csv file below. It is read here in your browser and never sent anywhere.
  3. Save the cleaned file, then upload it in the CMS under Field log → Merlin Bird ID → Cleaned eBird file and publish.

Dansk: Merlin gemmer dine fugle i eBird. Hent dine data på ebird.org (My eBird → Download my data), vælg filen MyEBirdData.csv her, og gem den rensede fil. Siden fjerner koordinater og alt andet end art, dato, kommune, tjekliste-id og foto-numre. Upload derefter den rensede fil i CMS'et under Field log.
